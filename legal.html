Cookies y almacenamiento del navegador

Esta web no instala cookies analíticas ni publicitarias. Utiliza almacenamiento del navegador para guardar la elección de privacidad y, solo si se acepta el almacenamiento opcional, recordar durante la sesión si ya se mostró el aviso de Instagram. La sesión de administración también se mantiene en el navegador durante la sesión de Carol.

Si se rechaza el almacenamiento opcional, no se guarda la preferencia del aviso y el popup de Instagram no se muestra. La elección de privacidad se conserva para respetar esa decisión. Se puede cambiar o retirar desde el botón siguiente y borrar los datos del sitio en la configuración del navegador.

  • Preferencia de privacidad (`localStorage`): guarda aceptar o rechazar hasta que se cambie desde esta página o se borren los datos del sitio.
  • Aviso de Instagram (`sessionStorage`): si se acepta el almacenamiento opcional, recuerda durante la sesión actual que el aviso ya se mostró.
  • Sesión de administración (`sessionStorage`): solo se utiliza cuando Carol inicia sesión en el panel; dura la sesión del navegador y no se usa para visitantes.
