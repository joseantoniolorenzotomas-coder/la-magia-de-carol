## Guardarraíles de Código y Calidad
1. **Seguridad por Diseño**: Queda prohibido el uso de claves en texto plano o librerías con vulnerabilidades conocidas [6, 7].
2. **Convenciones**: 
   - Usa nomenclatura descriptiva en español para clases CSS y variables.
   - Cada función debe incluir documentación JSDoc breve explicando su propósito [8].
3. **Metodología**: Aplica un flujo de "Bucle Autónomo": lee el código, planifica el cambio, implementa y verifica con tests visuales antes de dar la tarea por terminada [9, 10].
4. **Higiene de Contexto**: Si la ventana de contexto supera el 70%, solicita una compactación antes de continuar [11, 12].
